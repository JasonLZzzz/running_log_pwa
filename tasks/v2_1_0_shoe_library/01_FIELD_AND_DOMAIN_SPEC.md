# 01 — 鞋库字段与业务语义规范

## 一、核心实体与关联

- `Shoe`：**一双具体的实体跑鞋**，而不是某个鞋款型号；每双独立 `shoe_id`（UUID v4）。
- `RunRecord`：一条跑步活动记录，新增 `shoe_id: string | null`。本版 **0 或 1 双**，单选，不支持一次活动关联多双。例外情况可写入现有备注，不在此版拆分记录。
- 同一品牌、同一型号可以有多个 `Shoe`，即使配色完全相同，也依靠不同 ID/昵称区分。
- `shoe_id=null` 表示**未填写/暂时未知**，绝不由程序猜测为任意鞋。历史记录迁移默认全部为 null；用户后续自行补录。
- 鞋库与既有目标库（`goals`）平行存在，不改变任何训练标签、RPE、完成情况、目标关联逻辑。

## 二、鞋库字段表（冻结）

| 内部字段 | 中文名称 | 类型/必填 | 规则与示例 |
|---|---|---|---|
| `shoe_id` | 鞋子 ID | UUID v4，系统生成 | 永久唯一；即使鞋子重命名或退役也不变化 |
| `brand` | 品牌 | 非空字符串，必填 | `ASICS`；前后空白清理 |
| `model` | 鞋款型号 | 非空字符串，必填 | `Novablast 6`；前后空白清理 |
| `nickname` | 编号/昵称 | 非空字符串，必填但自动建议 | `1号`、`2号`、`草绿色那双`；可编辑 |
| `shoe_type` | 鞋子主要类型 | 可选枚举/null | 仅作为用户的粗粒度装备分类，见下表 |
| `status` | 使用状态 | 必填枚举 | `active` 在用 / `retired` 已退役 |
| `note` | 备注 | 字符串/null，可选 | 购买日期、尺码、穿着特点等，纯自由文本 |
| `schema_version` | 数据结构版本 | 系统维护 | 新版本合同中为 `2.0.0` |
| `created_at` | 建立时间 | 含时区 ISO 时间，系统维护 | 不因编辑/退役改变 |
| `updated_at` | 更新时间 | 含时区 ISO 时间，系统维护 | 编辑/退役时按既有严格单调时间策略更新 |

推荐展示标签：`品牌 型号 · 昵称`，例如 `ASICS Novablast 6 · 1号`。禁止仅凭品牌、型号或昵称作外键或自动合并，必须以 `shoe_id` 为唯一实体身份。

**昵称唯一性**：为减少误点，同一规范化品牌+型号组合内，建议拒绝完全重复的昵称并给出明确提示；比较时忽略首尾空白及英文大小写，不要擅自进行模糊型号合并。同名不同型号或不同品牌允许存在。若 Codex 发现此规则与现有数据/UX 冲突，需先报告。

**默认编号**：新建时可依照当前同品牌+型号的历史鞋数，建议下一个不冲突的 `N号`；即使先前一双已退役也不能重用已有昵称。人工输入优先，用户不需要自己维护内部 ID。

### 鞋子主要类型：选项及含义

| code | 中文 | 说明 |
|---|---|---|
| `daily` | 日常训练鞋 | 主要用来完成日常基础训练、轻松跑等 |
| `speed` | 速度训练鞋 | 主要用来完成节奏、阈值、间歇等质量课 |
| `race` | 竞速鞋 | 主要定位是比赛或竞速使用 |
| `trail` | 越野鞋 | 主要用来适应越野/山径等环境 |
| `other` | 其他 | 以上归类不合适时使用；可以在备注说明 |
| `null` | 未填写 | 未指定该鞋的主要类型；允许保存 |

**语义边界**：上述选项是“鞋子主要类型”的便捷展示，并非严格互斥的技术属性维度（例如越野竞速鞋会跨越两种用途）。不得依据 `shoe_type` 自动推断训练计划强度、路线、路面、跑鞋性能，或用于严肃的互斥统计。未来如果要严谨分析鞋子用途/场景，可另行设计正交字段；本版不得扩展。

## 三、状态与历史约束

- `active`：日常选择器中默认展示。
- `retired`：默认隐藏于快速选择，但历史记录仍可展示，历史补录与编辑时可以显式“显示已退役”。
- 允许对已退役鞋再次编辑或恢复在用；**退役不等于删除**。
- V2.1.0 不提供硬删除鞋库实体；防止历史引用失效。错误建库条目可先修改或退役。
- 修改鞋款名称或昵称后，历史记录仍引用相同 `shoe_id`；历史页显示鞋库当前名称。这是明确的“动态显示”，不是训练时刻名称快照。
- 不能因为鞋库没有鞋、某双已退役，自动填入某双或擦除原记录用鞋。

## 四、不在范围的内容

跑鞋累计公里数、跑鞋使用寿命、鞋子图片、价格/购买记录专用字段、Diagrun 同步、Garmin 同步、同一训练多双鞋、智能选鞋推荐、自动猜测旧记录用鞋、鞋型功效比较，全部暂缓。
